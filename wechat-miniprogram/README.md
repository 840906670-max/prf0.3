# 个人简历微信小程序

这是网址版个人简历的微信小程序外壳，首页直接通过 `web-view` 打开：

`https://prf0-3.pages.dev/`

## 开发者工具预览

导入 `wechat-miniprogram` 文件夹后点击编译。如果本地模拟器提示 `web-view` 业务域名校验，打开“详情 → 本地设置”，勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。

## 正式发布

在微信公众平台的“开发管理 → 开发设置 → 业务域名”中添加：

`prf0-3.pages.dev`

正式发布前如平台要求校验文件，将校验文件放到网站根目录并重新部署，再回到公众平台完成校验。

`native-backup-20261109/` 保留了此前原生组件版本，便于回滚。
